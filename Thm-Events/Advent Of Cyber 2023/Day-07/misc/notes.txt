#WHAT IS A LOG
 is a digital trail of what happens with a computer system or application behind the scenes. it recodes important evemts, errors, actions e.t.c
 
#WHAT IS A PROXY SERVER
in simple terms a proxy server is an intermediary between internal system and the internet

A proxy server offers enhanced visibility into network traffic and user activities, since it logs all web requests and responses. This enables system administrators and security analysts to monitor which websites users access, when, and how much bandwidth is used. It also allows administrators to enforce policies and block specific websites or content categories.


#ExAMPLES OF MALICIOUS ACTIVITIES
1. Malware downloading - Connection to a known malicious URL binary (e.g. www[.]evil[.]com/malicious[.]exe)
2. Data exfiltrations - High count of outbound bandwidth due to file upload (e.g. outbound connection to OneDrive)
3. C2 Beaconing - High count of outbound connections to a single domain in regular intervals (e.g. connections every five minutes to a single domain)

#tools
1. cat-Short for concatenate, allows to combine and display the contents of multiple files. 
2. less: The less command allows to view the contents of a file one page at a time.
3. head: The head command lets you view the contents at the top of the file
4. tail: In contrast to the head command, the tail command allows you to view the end of the file easily
5. wc: The wc command stands for word count. It's a command-line tool that counts the number of lines, words, and characters in a text file.
6. nl: The nl command stands for number lines. It renders the contents of the file in a numbered line format.
7. cut: allows you to extract specific sections (columns) of lines from a file or input stream by "cutting" the line into columns based on a delimiter and selecting which columns to display. This can be done using the -d option (for delimiter) and the -f for position.

This can be done using the -d option (for delimiter) and the -f for position. The example below uses space (' ') as its delimiter and only displays the timestamp (column #1 after cutting the log with space).

#CHOPPING DOWN THE PROXY LOG

Log Format: timestamp - source_ip - domain:port - http_method - http_uri - status_code - response_size - user_agent

#linux pipes

In Linux or Unix-like operating systems, a pipe (or the "|" character) is a way to connect two or more commands to make them work together seamlessly.
It allows to use the output of one command as input for another
